# 블로그를 시작합니다! 🎉

안녕하세요! Jekyll로 만든 GitHub Pages 블로그에 오신 것을 환영합니다.

## Jekyll이란?

Jekyll은 **정적 사이트 생성기**입니다. 마크다운 파일을 HTML로 변환해줍니다.

### 장점

- **무료 호스팅** - GitHub Pages에서 무료로 사용 가능
- **마크다운 지원** - 쉽게 글 작성 가능
- **커스텀 테마** - 다양한 테마 적용 가능
- **버전 관리** - Git으로 모든 변경 이력 관리

## 앞으로의 계획

이 블로그에서는 다음과 같은 내용을 공유할 예정입니다:

1. 개발 학습 기록
2. 프로젝트 회고
3. 유용한 팁과 트릭

함께 성장해봐요! 🚀
